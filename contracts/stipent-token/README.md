# STIPENT Token (STPN)

## Overview
STIPENT (STPN) is a consumptive utility token deployed on the Polygon blockchain and governed by Internset DAO.

This repository contains the official smart contract source code published for transparency, governance documentation, and technical reference within the Internset DAO ecosystem.
